# SpriteForge 1.1.4

## Installation

1. Extract the ZIP into your Godot project's root directory, alongside `project.godot`.
2. Confirm that `res://addons/sprite_forge/plugin.cfg` exists.
3. Open the project in Godot 4 and enable **SpriteForge** under **Project > Project Settings > Plugins**.
4. Open **SpriteForge** from the editor's bottom panel.

When updating an existing installation, replace the existing `addons/sprite_forge` folder with the folder from this archive. Preserve any personal modifications first.

See `CHANGELOG.md` for release changes and `ARCHITECTURE.md` for component responsibilities and test commands.
